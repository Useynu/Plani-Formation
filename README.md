\# Plani-Formation



\## Présentation

Plani-Formation est une application web destinée à faciliter la gestion des plannings de formation.



\## Objectif

Permettre de planifier les cours en associant :

\- Un formateur

\- Une salle

\- Un groupe

\- Une date et une heure



\## Technologies utilisées

\- Backend : NestJS

\- Frontend : React

\- Langage : TypeScript

\- Base de données : PostgreSQL

\- Gestion de versions : Git et GitHub



\## Fonctionnalités prévues

\- Gestion des formateurs

\- Gestion des salles

\- Gestion des groupes

\- Gestion des cours

\- Détection des conflits de planning

\- Affichage du calendrier des formations
